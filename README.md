# rpg

A personal, whimsical RPG layer over dev work: XP, levels, and *Dungeon Crawler Carl*-style achievements for commits, PRs, reviews, and Claude Code sessions. It's a local Tauri tray app with overlay pop-ups, sound bytes, and a character-sheet site.

The design lives in [`docs/superpowers/specs/2026-11-23-xp-achievements-design.md`](docs/superpowers/specs/2026-11-23-xp-achievements-design.md).
